# StoryQ Studio móvil

Prototipo de Regina Freyman exportado de Google AI Studio y compilado para GitHub Pages el 15 de octubre de 2026. Conserva el Studio original en la raíz.

No requiere cuenta de Google ni claves de IA. El análisis complementario usa reglas de coincidencia de expresiones y no un modelo generativo. Los datos permanecen en el navegador y dispositivo; no se sincronizan con el Studio original.

Las fuentes tipográficas se cargan de Google Fonts. El reporte se puede imprimir o guardar como PDF desde el navegador.
